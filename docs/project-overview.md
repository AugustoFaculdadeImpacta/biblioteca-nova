# Visão Geral do Projeto - Sistema de Biblioteca

## 1. Descrição do Sistema
Sistema Web completo para gerenciamento de acervo, usuários e controle de empréstimos de uma biblioteca.

## 2. Objetivos
- Cadastrar e gerenciar categorias de livros e os livros do acervo.
- Cadastrar usuários do sistema.
- Registrar empréstimos e devoluções com controle de status.

## 3. Arquitetura e Stack Tecnológica
- **Frontend**: Reflex (Framework Python para interfaces Web com renderização em React).
- **Backend**: Xano (Plataforma BaaS com API REST e banco de dados relacional).
- **Gerenciamento de Mudanças**: OpenSpec.
- **Controle de Versão**: Git e GitHub.

## 4. Restrições
- Não utilizar bibliotecas externas de UI fora do ecossistema do Reflex.
- A pasta `.venv` nunca deve ser commitada no Git.
